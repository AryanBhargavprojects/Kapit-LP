Error Reference

Every error the Kapit API can return includes a structured recovery object so agents know exactly what to do next.

401 Authentication Error
authentication-error non-retriable → 500 Internal Error
internal-error retriable → 400 Invalid Request
invalid-request non-retriable → 404 Market Not Found
market-not-found non-retriable → 404 Not Found
not-found non-retriable → 501 Not Ready
not-ready non-retriable → 403 Permission Denied
permission-denied non-retriable → 429 Rate Limited
rate-limited retriable → 404 Symbol Not Found
symbol-not-found non-retriable → 400 Unsupported Asset Class
unsupported-asset-class non-retriable → 502 Upstream Bad Response
upstream-bad-response retriable → 502 Upstream Error
upstream-error retriable → 502 Upstream Rate Limited
upstream-rate-limited retriable → 504 Upstream Timeout
